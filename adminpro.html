      Módulos visíveis para os moradores
      Marque o que os moradores podem ver no portal. Só aparecem aqui os módulos liberados pela administração da plataforma para este condomínio. Administradores e gestores continuam vendo tudo o que estiver liberado.
      📱
      WhatsApp Automático
      Não configurado
      Como configurar a Z-API:
      1. Acesse app.z-api.io e crie uma conta.
      2. Crie uma instância → escaneie o QR Code com seu WhatsApp.
      3. Copie o Instance ID e o Token abaixo.
      WhatsApp oficial da Meta (grátis no seu volume). As chaves ficam seguras no Supabase (não no site).

      Passo a passo (1x):
      1. Crie um app em developers.facebook.com → produto WhatsApp → conecte seu número dedicado.
      2. Crie um modelo (template) de mensagem, categoria Utilidade, corpo:
      🔔 Aviso do seu condomínio:\n\n{{1}}
      3. No Supabase → Edge Functions → Secrets, adicione: WHATSAPP_TOKEN, WHATSAPP_PHONE_ID, WHATSAPP_TEMPLATE (nome do modelo) e WHATSAPP_LANG (ex: pt_BR).
      4. Republique a Edge Function notificar (código novo que enviei) e teste abaixo.
      Evolution API (grátis, você hospeda). As chaves ficam seguras no Supabase.

      Passo a passo:
      1. Suba o Evolution API num servidor com HTTPS (VPS ou Railway/Render). Repositório: github.com/EvolutionAPI/evolution-api.
      2. Crie uma instância e escaneie o QR Code com o WhatsApp do seu número dedicado.
      3. No Supabase → Edge Functions → Secrets, adicione: EVOLUTION_URL (ex: https://seu-servidor.com), EVOLUTION_KEY (a API key) e EVOLUTION_INSTANCE (nome da instância).
      4. Republique a Edge Function notificar e teste abaixo.
      ✉️
      E-mail Automático (Supabase + Resend)
      Via Edge Function
      O envio de e-mail é feito pelo seu Supabase (Edge Function notificar) usando o Resend. A chave fica segura no servidor — nada de credencial no site.

      Passo a passo (uma vez só):
      1. Crie conta no resend.com e copie a API Key.
      2. No Supabase → Edge Functions → publique a função notificar (código no arquivo supabase/functions/notificar).
      3. No Supabase → Project Settings → Edge Functions → Secrets, adicione RESEND_API_KEY e EMAIL_FROM.
      4. Teste abaixo. ✅
